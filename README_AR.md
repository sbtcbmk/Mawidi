# موعدي — Android 1.2.0 (Release Candidate)

هذه هي حزمة المرحلة الأخيرة من المشروع من ناحية الكود والبنية.

## المنجز
- المواعيد والملاحظات والأذكار والمعلومات من واجهة التطبيق.
- تخزين محلي مستمر.
- نسخ احتياطي واستعادة JSON.
- إشعارات Android الأصلية.
- تذكير قبل الموعد.
- تكرار يومي/أسبوعي/شهري.
- إعادة جدولة التنبيهات بعد إعادة تشغيل الجهاز.
- تسجيل حساب Firebase بالبريد وكلمة المرور.
- تسجيل الدخول والخروج.
- Cloud Firestore لحفظ بيانات المستخدم.
- استرداد البيانات السحابية بعد تسجيل الدخول.
- قواعد Firestore تمنع المستخدم من الوصول إلى بيانات مستخدم آخر.
- استمرار التشغيل المحلي عند عدم توفر الإنترنت.
- واجهة ثنائية اللغة الموجودة في النسخة الحالية.

## المطلوب مرة واحدة قبل إخراج APK النهائي
1. إنشاء مشروع في Firebase.
2. إضافة تطبيق Android بالحزمة:
   `com.maw3idi.app`
3. تفعيل:
   - Authentication > Email/Password
   - Cloud Firestore
4. تنزيل `google-services.json` الحقيقي ووضعه في:
   `app/google-services.json`
5. فتح المشروع في Android Studio.
6. تنفيذ:
   `Build > Generate Signed Bundle / APK`
7. إنشاء مفتاح توقيع Release وحفظه في مكان آمن.

## مهم
لا توجد مفاتيح Firebase حقيقية داخل هذه الحزمة، ولا يجوز استخدام ملف المثال كأنه ملف إعداد حقيقي.
التطبيق المحلي والتنبيهات والنسخ الاحتياطي لا تعتمد على Firebase.

## ملف المثال
`app/google-services.json.example`

## حالة البناء
تم تجهيز ملفات Gradle والإضافات والإصدارات للحزمة النهائية، لكن لا يمكن إصدار APK موقّع من هذه البيئة من دون Android SDK/Gradle ومفتاح توقيع وملف Firebase الحقيقي.
